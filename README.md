# Video on Demand (VOD) Application – Spec Driven Development

## Overview
This project is a frontend-only Video on Demand (VOD) movie browsing application built as part of the AI Readiness Program: Prompt Engineering & Spec-Driven Development workshop.

The application allows users to explore, search, and view details of movies using an external movie database API. The entire solution is designed and implemented following Spec-Driven Development (SDD) principles.

## Objectives
- Demonstrate structured planning using SDD
- Build a medium-complex frontend application
- Integrate with an external public API
- Maintain strict adherence to defined scope and constraints

## Features
- Trending movies browsing
- Top rated movies browsing
- Search movies by title
- Movie detail page with overview, cast, and ratings

## Out of Scope
- Video streaming
- Authentication
- Payments or subscriptions
- Backend or database

## Tech Stack
- Frontend Framework: React
- Styling: CSS / Tailwind CSS
- API: The Movie Database (TMDB)
- SDD Tooling: GitHub Spec Kit

## Project Structure
- `constitution/` – Project scope and rules
- `features/` – Feature specifications
- `tasks/` – Task breakdown aligned to specs
- `src/` – Frontend implementation

## How to Run
1. Install dependencies
2. Add TMDB API key to `.env`
3. Start the development server

## Notes
This project focuses on browsing and discovery experience only and strictly follows Spec-Driven Development.
